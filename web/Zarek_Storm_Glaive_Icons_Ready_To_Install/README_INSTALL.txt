ZAREK — STORM GLAIVE ICONS
===========================
Five ready-to-use 128x128 WebP icons following the README2.md naming convention.

INSTALL
1. Extract this ZIP.
2. Copy the included public folder into your main fight-royale/web folder.
   Choose Merge folders if prompted. Do not replace any other fighter icons.
3. You should end up with:
     web/public/icons/chars/zarek.webp
     web/public/icons/skills/glaive-z.webp
     web/public/icons/skills/glaive-x.webp
     web/public/icons/skills/glaive-c.webp
     web/public/icons/skills/glaive-v.webp
4. Start or refresh the game (npm run dev; Ctrl+Shift+R if cached).

SKILLS
Z = Flash Reversal
X = Thunder Barrage
C = Heaven's Judgment
V = Arc Flash (bonus skill)

Notes:
- Icons do not require SQL migration or Python installation.
- Portrait shows Zarek's planned look (silver-haired storm duelist), rather than the temporary nyx.vrm.
- Zarek_4x4_icon_sheet.png shows the README2.md sheet layout for reference.
