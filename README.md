# Fight-Royale

Anime cel-shaded arena fighter.

- `web/` - the browser version (Next.js + three.js): duels vs CPU, co-op survival waves, online play by room code. Deploy on Vercel with **Root Directory** set to `web`. See [web/README.md](web/README.md).
- Project root - the original Godot 4.7 prototype.
